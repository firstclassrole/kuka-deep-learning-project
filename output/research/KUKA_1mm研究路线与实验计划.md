# KUKA 逐点 1 mm 目标：研究路线与实验计划

日期：2026-10-17。状态：重新规划，以下阶段尚未执行；本文件不是“已达到1 mm”的实验报告。

## 1. 明确目标

用户已经确认：**每个测试目标的三维末端位置误差都不超过1 mm**，不是测试集平均值不超过1 mm。

位置误差定义为：`1000 × ||FK(q预测).位置 − 目标位置||₂`，单位mm。按`≤1.0 mm`验收，不能用每个坐标轴均小于1mm来替代三维欧氏距离要求。

当前场景为七轴 **KUKA LBR iiwa 14 R820**；基座 `/LBRiiwa14R820`，末端为已经配置的 `link8_resp` 对象坐标系。先完成这个固定模型上的静态运动学实验。工具TCP的重新定义、碰撞筛选、动态轨迹和实机标定是后续阶段。

朝向误差继续使用最短SO(3)旋转角并单独报告。暂建议把`≤0.5°`作为额外的完整位姿实验标准，但这不是用户已经确认的要求。分别报告“位置达标率”和“位置+朝向联合达标率”，不混用。

有限测试集全部达标，只能证明这批测试通过，不能证明任意工作空间目标都必然达标。

## 2. 依据哪些较好结果

| 文献 | 已核实的结果或做法 | 在本项目中的作用 |
| --- | --- | --- |
| [Lu、Zou、Jiang，2022，综述[39]](https://www.mdpi.com/1424-8220/22/22/8909) | 六轴xArm6仿真；分区网络提供初值，Newton–Raphson精修后各坐标轴MAE约0.55–0.59微米 | 主线参考：把神经网络与几何求解结合。不能把六轴公式或微米结果直接移植成七轴KUKA结论 |
| [Vu等，2023，综述[7]](https://arxiv.org/abs/2211.04275) | 对同型号KUKA LBR iiwa 14 R820，网络学习冗余参数，再由解析IK给出关节角；报告约32微秒IK时间 | 后续优先研究的同型号路线；先核对解析链、坐标系和冗余参数定义，不承诺Python实现复制其时间 |
| [CycleIK，2023，综述[43]](https://arxiv.org/html/2307.11554) | 纯MLP在NICOL八轴小工作区报告0.295mm；用FK后的末端误差训练，并对冗余关节设置偏好 | 当神经网络初值质量不足时，优先改训练目标；不是只增加隐藏层 |

Lu的数字是各坐标轴统计，CycleIK使用其论文定义的轴平均，均不能代替本项目的三维欧氏验收指标。这些文献支持技术路线，不构成对当前KUKA精度的保证。

## 3. 选定主线

```text
目标位置 + 朝向
       ↓
神经网络给出候选关节角
       ↓
七轴、有明确关节限位的数值IK修正
       ↓
用同一KUKA模型重新计算末端位姿
       ↓
位置≤1mm 且关节合法 → 返回候选解
否则 → 在固定预算内换初值重试；仍失败则明确记录失败
```

原有1层×160网络保留作历史基线。是否提高到2–4层×128/256，由验证集表现决定；80层不作为第一阶段默认方案。以上新增宽度是开发候选，不是声称照抄作者原版网络。

首个数值实现优先使用官方 [CoppeliaSim simIK](https://manual.coppeliarobotics.com/en/kinematicsPlugin.htm) 的冗余机械臂求解能力，减少新手阶段手写雅可比出错。完成后再考虑独立NumPy或其他可微运动学实现，支持FK损失训练与脱离仿真软件部署。

## 4. 分阶段执行与完成条件

| 阶段 | 具体工作 | 交付物 / 完成条件 |
| --- | --- | --- |
| 0：冻结定义 | 固定机器人、基座、末端、限位、XYZW四元数顺序和位置单位；确定开发集与最终测试规则 | 配置清单与验收脚本，位置明确为欧氏距离；基础FK一致性通过 |
| 1：纯数值基线 | 不依赖网络，使用固定初值及有限重试，在开发/验证目标上求解完整位姿 | 每条记录误差、越限、重试与时间；证明该模型与求解设置能稳定达到1mm，再开展NN比较 |
| 2：网络＋数值修正 | 使用现有网络给初值；复用相同求解器、限位、停止条件和重试预算 | 与纯数值方法同条件比较；观察首次收敛、重试次数、耗时及失败率 |
| 3：针对性改进 | 若网络没有带来收益，先参考CycleIK引入FK位姿损失和冗余偏好；必要时增加数据、比较少量网络结构 | 用验证集确定方案；有可解释的改进证据，不把数值修正的全部收益算成神经网络的功劳 |
| 4：冻结后独立验收 | 固定全部参数、模型与重试策略，再生成新的独立可达测试目标；逐条验收 | 所有测试目标位置≤1mm、0条越限、0条未返回有效解；报告最大值与全部失败 |
| 5：扩展研究 | 根据论文时间与实际需求，选择Vu的冗余参数＋解析IK，或增加碰撞与轨迹验证 | 单独实验，不与前述静态精度结论混淆 |

阶段1若仍有超过1mm的目标，先查坐标系、关节顺序、限位、奇异附近收敛和多初值策略。此时不通过增加网络层数掩盖几何求解问题。

阶段2若纯数值方法已经同样快且同样稳定，保留该结果；神经网络的研究价值需要用进一步实验说明，不能预设有优势。

## 5. 数据安排：保留成果，重新独立验收

- 现有10,000条数据已完成采集与同模型回放。继续使用原训练7,000条、验证2,000条开展开发。
- 原测试1,000条已经观察过，其806mm基线只能继续作为历史诊断，不能称为后续方法从未见过的最终测试。
- 最终先规划1,000条新目标：500条在既定限位范围随机采样，250条靠近关节限位，250条接近伸直或低可操作度区域。真实目标由合法关节角经FK生成，以确认可达。
- 最终目标生成的随机种子、范围、数量和压力样本判定规则，应在生成前固定；与开发数据去除完全重复项。若压力区域不能生成足量合法目标，要在验收前修改并冻结生成规则，不能看完失败结果再删目标。
- 真实关节标签只用于确认可达和核对FK，**不得作为求解器初值，也不得用于为某条测试目标挑选重试分支**。
- 所有数据先保留关节标签，但最终主要按末端位姿评估。七轴的一组正确关节角不必与随机采样标签相同。
- 当前采样尚未做碰撞筛选。这一阶段先验收运动学；建立实用无碰撞控制目标时，需要另建并明确冻结碰撞模型与目标集。

暂不直接扩大到百万数据。若阶段3验证结果显示数据覆盖确实是瓶颈，再分批增加到50,000或100,000条，并保持拆分和最终测试隔离。

## 6. 公平对照实验

| 方案 | 输入 / 初值 | 要回答的问题 |
| --- | --- | --- |
| A：纯网络 | 目标位姿→关节角 | 原始近似器本身有多准、有多快？ |
| B：纯数值IK | 固定初值＋预先定义的重试初值 | 没有神经网络时，几何求解能否满足1mm？ |
| C：网络＋数值IK | 网络初值＋与B相同的后备策略 | 网络是否减少迭代、重试与时间，或提高同预算成功率？ |
| D：训练集近邻＋数值IK（建议） | 只从训练数据检索近邻初值 | 网络相较简单数据检索是否仍有价值？ |

B/C/D使用相同目标、限位、内部停止容差和总预算。重试、检索、网络推理和数值修正都计入总时间；失败样本也记录耗时。单独报告冷启动与稳定运行时间，不把CoppeliaSim启动耗时算成单次IK时间。

内部停止容差初步建议位置0.1mm、朝向0.1°，给1mm外部验收留余量。每次初值最多100次数值迭代、每目标最多16个初值、目标总预算初步1秒；这些是开发起点，不是已经验证的实时性能承诺。最终根据验证集确定并冻结，不能在最终测试上逐条调大预算直到全部通过。

## 7. 必须报告的指标

| 指标 | 报告方式 |
| --- | --- |
| 位置误差 | 全样本均值、中位数、P95、最大值；核心是最大值≤1mm |
| 超标数量 | 三维位置误差>1mm的样本数，不只给百分比 |
| 无解 / 超时 / 非有限输出 | 分别计数，都进入总样本分母；不能删除失败行 |
| 关节限位 | 越限数量；任何越限候选不能作为有效输出 |
| 朝向误差 | 测地角均值/P95/最大值；另报待确认0.5°标准下的联合达标率 |
| 效率 | 包含全部重试的每目标耗时均值、P95、最大值，及迭代/重试分布 |
| 神经网络贡献 | 同精度/同预算下相较纯数值基线的耗时、首次成功率、失败率变化 |

若有目标未返回合法候选，则“有效候选的最大位置误差”不能单独用来宣布全体通过；整体验收必须明确失败。只有所有预定目标返回合法候选且均≤1mm，才能写“这批冻结测试全部达标”。
