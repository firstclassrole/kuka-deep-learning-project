### 正运动学不会主动选择避障动作

在固定几何和基座的刚体模型中，正运动学是：

\[
T_E = f(q).
\]

这里 q 是各关节变量，T_E 包含末端位置与朝向。它回答“这组角度使末端在哪里”。障碍物会限制哪些配置允许出现，但不会自动改变这一几何映射。

因此，用绕障过程中记录的“关节角度 → 末端位置”训练模型，可以学习该映射；不能据此认为模型已经学会主动选择避障动作。这是根据书中定义对项目作出的推论。

### 同一末端目标，可以对应碰撞与不碰撞的两组角度

最贴近当前项目的是图 4.3：书内 p.104 / PDF 第 112 页。图中到同一个目标 B 有两种关节配置；离当前配置较近的一种会碰到障碍物，因此必须选择另一种。书中还提出，让逆解程序接收当前关节状态，以帮助选择较近的解。

对项目的推论：如果学习“目标位姿 → 关节角度”，数据标签需要有一致的选解规则。当前配置可以帮助区分逆解分支；若要适应变化的障碍物布局，输入还需要包含相应环境信息。同一输入对应不同绕行方式时，直接回归一个平均角度可能得不到有效动作。

### 一圈安全采样点不等于一条安全轨迹

§7.3（书 p.203 / PDF211）指出，关节空间插值的末端路径在采样点之间可能复杂。书 p.216 / PDF224 进一步说明，带抛物线过渡的线性样条不一定实际通过每个 via point，平滑连接可能偏离这些点。

§7.5（书 pp.220–221 / PDF228–229）展示了端点可达但中间不可达、以及路径上无法维持同一逆解分支的情况。§13.2 则强调模拟实际空间路径来判断碰撞。

对项目的推论：标签生成后，还应检查整条机械臂的连杆和实际连接方式，而不只检查末端或离散端点。增加采样密度可以减少漏检，但有限点检查本身不能宣称为连续无碰撞保证。

### “规定在平面上”与“接触平面”要分开

§11.3 区分接触产生的自然约束和用户规定的任务约束。

- 规定末端保持 z = z0，而不接触任何物体：可以先研究几何路径与运动学约束。
- 末端实际压在桌面、沿墙面或槽道运动：涉及接触力、力控制以及接触状态。
- 主动绕障：要求选取无碰撞配置和过渡。
- 被障碍物挡住：要求描述实际接触及其对运动的影响；它不等同于主动绕障。

## 3. Lewis 等：神经网络控制的实际内容

本地 untitled.pdf 的书名与三位作者已在标题页核实。正文从 PDF 第 28 页的书内 p.1 开始，正文页码通常为 PDF = 书内 + 27；目录个别条目与实际章首页存在差异，应以正文为准。本地文件部分前置页为空白，未从版权页确认出版年份。

这本书的主线是把神经网络放入反馈控制系统，逼近未知非线性项，并设计权重更新与控制律。序言（PDF25–27）明确强调稳定性、鲁棒性和无源性。它适合作为神经网络机器人控制的理论基础，其主要方法与现代离线训练的角度预测器需要区分。

| 内容 | 核实位置 | 应理解的内容 |
|---|---|---|
| 第 1 章：神经网络结构与训练 | §1.3，书 pp.33–60 / PDF60–87 | 输入向量、目标输出向量、误差、梯度下降、反向传播 |
| 输入输出配对及批量训练 | 书 pp.37–40 / PDF64–67 | 一个样本可以有多个输入分量和多个输出分量 |
| 第 3 章：机器人动力学与控制 | 书 p.125 起 / PDF152 起 | 位姿、速度、力矩与动力学的区别；轨迹跟踪控制 |
| 第 4 章：神经网络机器人控制 | 书 p.175 起 / PDF202 起 | 用 NN 逼近动力学未知项，结合反馈控制与在线调权 |
| §5.1：神经网络力控制 | 书 pp.224–234 / PDF251–261 | 与已知表面接触时的位置/力混合控制 |
| 第 9 章：系统辨识与状态估计 | 实际书 pp.415–420 / PDF442–447 | 根据状态、控制输入和必要历史估计后续状态；目录将章首页写为 413，应以正文为准 |

第 1 章把训练样本写成一对向量 (X, Y)，而不是要求所有输入属于同一个物理量。各分量可以表示不同状态，只要定义明确、配对一致。书中的训练迭代编号 k 也不一定等于机器人运动的时间编号 t。

第 4 章的神经网络通常参与计算控制力矩或动力学补偿项，其学习目标不能直接套用为“下一时刻关节角度”。即使跟踪误差有界，也不能把它解释成对任意障碍物的避障保证。

第 4 章还研究利用跟踪误差在线调权的方法，不一定需要预先给出理想动力学补偿量的标签。书中对此使用的“unsupervised backpropagation”是其控制语境下的术语；系统仍有期望轨迹和反馈误差，不能直接等同于现代聚类式无监督学习。

§5.1 研究已知接触表面的约束、切向轨迹跟踪和法向力跟踪，适合用来理解“末端被物理表面限制”。它不直接给出通用障碍物绕行或突发碰撞恢复算法。

| 页码 | 要点 |

| 1–6 | 简化 CAD 网格，按刚性连杆组织外观几何体 |

最重要的区别是：dynamic/static 描述物体是否受力运动；respondable/non-respondable 描述是否产生物理碰撞响应。固定障碍物可以是 static，同时仍应在适当配置下对接触产生响应。教程也把较精细的可见模型和简化的动力学模型分开。

对项目的推论：若研究“被挡住”的真实仿真结果，需要检查物理响应和驱动方式；若只是几何避障，可以先用碰撞/距离判定筛选配置。画出了障碍物，并不代表已经完成物理接触配置或避障规划。这份教程本身主要教建模，不包含完整的避障数据生成流程。

## 5. 后续讨论模型时应统一的定义

令 n 为所选机械臂的实际关节数；目前没有依据固定为 6 或 7。目标位姿中的朝向是否固定，也需要写清。

| 学习任务 | 示例输入 | 输出或标签 | 回答的问题 |
|---|---|---|---|
| 正运动学学习 | 关节角度 q | 末端位姿 T | 这组角度使末端在哪里？ |
| 环境条件下的逆解选择 | 目标位姿 T*、当前 q、障碍物描述 o | 选出的有效目标角度 q* | 这个目标可以选哪组角度？ |
| 根据示范学习逐步动作 | 当前状态、轨迹目标、障碍物描述 | 安全示范中的下一目标角度或角度增量 | 下一步应该怎么动？ |
| 实际运动预测 | 当前角度与速度、驱动指令、环境/接触信息或相关历史 | 后续实际角度 | 给定这些条件，实际上会怎么动？ |
| 本书的 NN 动力学控制 | 状态、期望轨迹、跟踪误差等 | 力矩或动力学补偿项 | 怎样施力使机械臂跟踪轨迹？ |

这些任务的输入和标签不同。前面对话从正运动学逐渐转到了学习下一步动作，后续应明确说明这个变化，不能仅因为使用了轨迹就默认它们是同一个问题。

采用监督学习时，可将同一时刻相关量拼成输入向量，标签由同一条示范中的对应输出提供。也可以用一段历史作为矩阵输入；一整条轨迹不必压成一行。对轨迹数据，训练集和测试集宜按完整轨迹或场景划分，避免相邻点泄漏造成过于乐观的评价。这些是项目方法建议，不是教材指定的实验方案。

若第一阶段采用主动避障示范，标签应来自规划并核查过的目标关节轨迹；若研究被挡住后的实际运动，标签应来自含接触的实际仿真记录。目标角度与测得角度应分别保存，因为有控制误差或接触时二者可能不同。

特别是，记录“被挡住后停止”的样本，可以用于学习哪里会停住；这些样本不会自动提供应该从哪一侧绕开的动作标签。预测接触结果与学习绕行动作，可以分别形成两个研究问题。

## 6. 建议的阅读顺序与研究范围

1. Craig 第 2、3、4 章：明确坐标系、正逆运动学和多解。
2. Craig 第 7 章：明确路径、时间参数和关节轨迹标签。
3. CoppeliaSim 教程：核查关节轴向、模型层级及碰撞响应。
4. Lewis 第 1 章和第 3、4 章的控制框架：明确训练与闭环控制的区别。
5. 若研究真实接触，再深入 Craig 第 11 章及 Lewis §5.1。

对项目的建议是先限定无接触的平面任务和一个简单障碍物，明确模型是在预测实际运动还是输出期望动作，再生成数据和建立基线。物理接触造成的 block 可以作为单独扩展，其状态和评价指标需要额外设计。两页初步报告可以先覆盖已读材料、这些任务区别、拟研究的问题及尚需明确的型号与实验范围。
