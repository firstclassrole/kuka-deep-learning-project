# TIAGo 神经网络与数值修正对照：验证集

读取 `tiago_01` 已有神经网络，先预测七个关节角，再使用已核对的正运动学模型进行有界阻尼最小二乘迭代。网络层数、权重和训练数据均未改变。

| 指标 | 只有神经网络 | 网络预测后数值修正 |
|---|---:|---:|
| 平均位置误差（mm） | 120.825 | 0.675 |
| 位置误差 P95（mm） | 263.750 | 0.908 |
| 平均朝向误差（度） | 29.896 | 0.146 |
| 朝向误差 P95（度） | 63.756 | 0.320 |
| 同时满足 10 mm / 5 度且限位内 | 1 / 2000 | 1981 / 2000 |

阈值仅用于教学比较，没有碰撞检查。本次 2000 条样本的数值修正批量计算耗时 0.491 秒；这不是单次在线调用的延迟测试。

这是一种“学习初值 + 数值求解”的混合方法，结果不能称为神经网络单独预测的精度，也不是第一篇论文原方法的严格复现。关节标签有多解时，应以末端位置、朝向及约束评估，修正后的关节角不必接近原来的那组标签。

默认使用验证集，开发期间在验证集比较方案。最终锁定方案后，才运行 `--split test`。本方法是局部迭代，没有多初值重启，可能失败；尚未进行碰撞、连续轨迹或真实机器人实验。

文件 `refined_angles.csv` 给出每条样本修正后的角度与误差；`refined_angles.npz` 保存初始和修正角度；`metrics.json` 保存完整对照数据。重复运行会更新本目录中的派生结果，原网络权重继续保留。
