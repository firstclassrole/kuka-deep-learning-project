# 深度实验：two

隐藏层共 2 层，参数量 28,167。输入 7 维，输出 7 个关节角，隐藏层采用 ReLU，输出采用线性激活。完整每层宽度见 `experiment_config.json`。

本次使用 10000 条原始数据，按随机种子 42 划分训练/验证/测试为 70%/20%/10%。缩放参数只从训练集拟合。最多训练 200 轮，本次完成 70 轮；验证关节 MSE 连续 25 轮未改善会提前停止，并恢复最佳检查点。不同网络提前停止的轮数可以不同。

| 验证集指标（2000 条样本） | 结果 |
|---|---:|
| 平均关节标签误差（度） | 22.14 |
| 平均末端位置误差（mm） | 110.21 |
| 位置误差 P95（mm） | 226.66 |
| 平均朝向误差（度） | 26.47 |
| 同时满足位置 <10 mm、朝向 <5 度和限位 | 0 / 2000 |

10 mm / 5 度是教学比较阈值，没有碰撞检查。本次不对测试集进行预测或评分。先用验证结果比较两层、十层和其他方案，锁定方案后再使用 `04_evaluate_tiago.py --split test` 做最终测试。

先查看 `validation_fk/结果解读.md`，其中包含末端误差解释。`training_curve.svg` 是训练与验证曲线；`history.csv` 是每轮损失；`model.npz` 是模型；`validation_predictions.csv` 是验证关节预测；原始样本划分保存在 `split_rows.npz`。

两层和十层保持相同训练设置。网络加深会同时增加参数量，比较时不能把差异全部归因于层数，也不能由一次随机种子实验断言普遍优劣。
