# 两层、十层与作者结构：直接运行说明

入口是 `07_run_depth.py`。已在你的 Python 3.12.1 / NumPy 2.5.4 环境中完成短程训练、保存、加载和 FK 评估检查，完整训练留给你起床后运行。

## 1. 打开正确的终端目录

在 PyCharm 底部 Terminal 的 PowerShell 中先执行：

```powershell
Set-Location -LiteralPath 'D:\Swansea-杜亦冯\biyeshj\output\tutorials\tiago_ik_beginner'
```

现有 `.venv` 继续使用，无需安装新依赖。这些是 PowerShell 命令，不是应输入到 Python `>>>` 中的代码。

## 2. 先跑两层

```powershell
.\.venv\Scripts\python.exe 07_run_depth.py --preset two
```

结构：输入 7 维 → 两个隐藏层，每层 160 个神经元和 ReLU → 7 维线性输出。

## 3. 两层完成后跑十层

```powershell
.\.venv\Scripts\python.exe 07_run_depth.py --preset ten
```

结构：输入 7 维 → 十个隐藏层，每层 160 个神经元和 ReLU → 7 维线性输出。这里的“十层”指十个隐藏层，另有一个输出层。

每个命令都会完成训练、恢复最佳验证检查点，并自动计算验证集的末端位置误差、朝向误差和关节限位。不用再手动接一条评估命令，也不加入数值 IK 修正，便于比较网络深度。

## 4. 再跑作者 80 层隐藏结构的适配版

```powershell
.\.venv\Scripts\python.exe 07_run_depth.py --preset author80
```

结构：20 个隐藏层各 128 神经元 → 40 个隐藏层各 256 神经元 → 20 个隐藏层各 128 神经元，共 80 个隐藏层，另外有输出层。

**这个入口是作者隐藏结构的 NumPy 适配版，不能写成“直接运行作者原源码”或“严格复现论文”。** 为保持对照设置一致，它采用教学训练器的线性输出、Adam 0.001、训练集 robust scaling、固定划分和最佳验证检查点。作者原模型用 tanh 输出，原 `training.py` 训练用 RMSprop，配置学习率为 0.1。全部差异会写入每次实验的 `experiment_config.json`。

## 5. 每次结果保存在哪里

| 命令 | 首次输出目录 | 隐藏结构 |
|---|---|---|
| `--preset two` | `runs/tiago_2layers_01` | 2 层，各 160 |
| `--preset ten` | `runs/tiago_10layers_01` | 10 层，各 160 |
| `--preset author80` | `runs/tiago_author80_structure_01` | 20×128、40×256、20×128 |

如果 `_01` 已存在，会自动使用 `_02`、`_03` 等新目录。运行完成后控制台也会打印实际输出目录。只有主动指定 `--out` 且目录已存在时才报错，不会覆盖旧实验。

每组完成后先打开：

- `实验结果.md`：这组网络的结构和主要验证结果。
- `validation_fk/结果解读.md`：位置、朝向和限位的详细表格。
- `training_curve.svg`：训练与验证曲线。
- `experiment_config.json`：层数、参数量、数据来源、实际训练设置。

所有方案都使用同一份 10,000 条数据、随机种子 42、训练/验证/测试 70%/20%/10%、Adam 0.001、batch 128、最多 200 轮。验证关节 MSE 连续 25 轮未改善会提前停止，不一定跑满 200 轮；停止轮数不同是正常情况。更深的网络不保证更好或更快。

本入口只预测和评分验证集，不在训练期间评分测试集。先比较验证集的平均位置误差、朝向误差和 P95，锁定方案后才做最终测试。

## 6. 最终测试留到方案锁定后

例如最终选中十层，且实际目录为 `runs/tiago_10layers_01`，再运行：

```powershell
.\.venv\Scripts\python.exe 04_evaluate_tiago.py --run runs/tiago_10layers_01 --split test
```

该命令可从保存的模型直接计算保留测试集的预测，不需要重训。测试报告位于该目录的 `fk_evaluation/结果解读.md`。10 mm / 5 度只是教学比较阈值，评估不包含碰撞或真实机器人实验。

## 7. 作者原源码已经准备在哪

你下载的源码已完整解压到 `references/author_v1/source`，原文件内容未改，来源与逐文件校验值在 `references/author_v1/full_source.source.json`。原项目的入口是 `training.py --name DeepMlp`，环境说明见其 `README.md` 和 `docker/Dockerfile`。

原项目使用 TensorFlow 2.14、Pykin、机器人 URDF/网格和日志依赖，还需要匹配的数据预处理文件。它没有安装在当前只有 NumPy 的 `.venv` 中，不能把上面的 `author80` 命令当作原版运行。严格原源码路线需要另建环境并核对输入数据与机器人模型；[TensorFlow 官方安装说明](https://www.tensorflow.org/install/pip)提供了环境安装要求。这一步与本次已验证可运行的三组结构对照分开。

想只检查配置而暂不训练，可在任一命令后加 `--check-only`，例如：

```powershell
.\.venv\Scripts\python.exe 07_run_depth.py --preset ten --check-only
```
